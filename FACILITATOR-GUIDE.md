# The Lab facilitator guide

## Before people arrive

1. On your laptop, open [Facilitator](https://brick.btrbot.com/facilitator/). Use the private facilitator link from the access card to sign in the first time.
2. Click **Connect a Mac → Show the big screen → Create pairing code**. On the projector Mac, open [Pair big screen](https://brick.btrbot.com/bigscreen/#/pair), enter the code, and select **Full screen**.
3. Confirm the dashboard says **1 connected** under **Big screen**. The projector Mac can return to the same room at [brick.btrbot.com/bigscreen](https://brick.btrbot.com/bigscreen).

To give a second Mac control, choose **Facilitate** in **Connect a Mac** and enter the new code at [Pair facilitator](https://brick.btrbot.com/facilitator/#/pair). Codes expire after 10 minutes and connect one browser. Keep the private facilitator link for recovery.

Before each run in the reusable room, use **Room tools → Session → Reset all…** if there’s a previous run. Leave the projector in the lobby. Participants join by scanning the QR or entering the room code at [The Lab](https://brick.btrbot.com/).

For music, open **Countdown music** on the projector, select **Enable music**, and set the volume. The projector loads the tracks from Hugin. Each timed activity gets a track, and the shuffle plays every available track before repeating. Pausing, resuming, restarting, or adding time keeps the same track. Music stops at zero. Select **Enable music** again after a refresh or room reset.

Set out one matching brick kit per person, with spare pieces available. Confirm the piece list and count for your event when you pack the kits. Set seats so each person has a neighbour they can talk to. Check the phone, dashboard and projector in a disposable room.

## Run of show · 40 minutes

| Time | Activity | Facilitator action |
|---:|---|---|
| 4 min | Join and choose an AI app | Participants make both sharing choices here. Watch the join count, then select **Open build plan**. |
| 6 min | Photograph the bricks and get instructions | Watch **have instructions** and **checked in without instructions**. Participants can use **Send manually** if sharing fails. At zero, tell everyone to start with what came back or with the pieces they have. |
| 5 min | Build | Select **Start build**. Phones in the AI handoff move to the build cue when participants return. |
| 3 min | Capture the first builds | Select **Capture builds**. Everyone saves a build photo, then reports what came back from the AI. If they got an idea, they save its name and an image or screenshot. The photo wall fills as builds arrive. |
| 4 min | Reveal, reflect and talk with a neighbour | Select **Start reflection** to show the first build pairs and start two minutes for the questions. Select **Start neighbour exchange** and give each person one minute to show their build and finish “I want to change…”. They can revise that line on their phone. |
| 6 min | Develop the idea | Select **Start make it yours**. Participants can copy a prompt containing their change and paste it into the same AI chat. |
| 4 min | Save the final card | Select **Open concept cards** to start the countdown. Everyone saves a name, a one-sentence description, an image or photo of a quick sketch, and a note on what changed. Watch how many reached the card and how many saved it. Add a minute if needed. |
| 8 min | Compare the cards and debrief | Select **Reveal cards & open vote**. The big screen shows the question beside the pairs, and one tap on the phone records the answer and finishes. Pick a pair and ask what prompted the change. If time allows, run **Final neighbour exchange** and use **Follow workshop** to return to the comparison. |

Use the stage strip to jump directly to a phase and the **Next** button to step through the normal sequence. Use **Pause timer**, **Resume timer**, **Restart timer**, or **+1 minute** to adjust the pace. If someone is stuck, ask for the **Builder reference** in their Session settings and open **Participant details** to find them.

The **Participant view** follows the current phase using sample data. Use its screen picker to see alternate screens in that phase, such as waiting or saving the first AI idea.

Compare the share of people who saved a first build and went on to save a final card. The November 12 baseline was 55 of 102 (54%). The final-card reach count helps distinguish people who never opened the form from people who opened it and had yet to submit.

## Debrief

Ask people to look at the pairs before you describe a pattern. How similar were the first suggestions? Which builds matched the AI plan? Where did the final ideas diverge?

Pick one pair. Ask the builder what prompted their change. Listen for a missing brick, a neighbour’s observation, a different audience, or an experience the builder wanted to create. Find someone who kept the first idea and ask what made it worth keeping. Invite one observation from the room before showing the results of **What changed most from the AI’s first idea?**

If the room needs an example, use **The Human and Agent Bridge**. The AI first suggested a brick bridge. The builder turned it into a meeting point where a human builds from one side and an AI agent builds from the other. Move to the Magic Button / Centaur / Cyborg slide when you transition to the multiplayer ending.

## Close and document

Open **Room tools → Session** to **Close session** when submissions are in and **Export results** for a private facilitator copy. For the public write-up, open **Room tools → Images** and check **Images approved for gervilabs.com** again just before publishing. Keep the image reference with the published photo and use the Gervi Labs contact route for withdrawal requests. Raw workshop data, including downloads and backup copies, has a maximum retention period of 90 days from joining.

To start a fresh rehearsal, open **Room tools → Session → Reset all…**, check the room name, and type its code in the confirmation dialog. The lobby returns to zero with the same QR and staff links. Previous drafts and pending uploads are cleared when phones reconnect. Export any results you need first.
